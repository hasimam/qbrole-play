# QBROLE — playable preview

[Play the first level](https://hasimam.github.io/qbrole-play/)

A 3D rolling-block puzzle. Desktop: arrow keys or WASD. Phone: on-screen directional controls. Roll the block upright into the glowing exit. Undo and restart are available.

This repository contains only the compiled browser build. The source is maintained separately. GitHub Pages serves the main branch directly; no login is required to play.

Initial release: first playable level, validated by 245 automated checks.
